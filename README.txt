# Mandala-OS Output Control: Quartet Session Report

This repository documents a successful implementation of a multi-personality output control system based on a custom prompt architecture referred to as **Mandala-OS**.

The included session log demonstrates the output of a fully structured **Quartet format** running across different AI platforms (GPT-4o, Gemini 2.5), without modification to syntax or character definitions. The system enabled coherent, multi-voice AI dialogue with stable structural integrity.
